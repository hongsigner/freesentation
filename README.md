# freesentation

프리젠테이션 폰트를 웹폰트로 사용하려는데 따로 배포된 것은 못찾아서 직접 올렸습니다.

### import 방식

	@import url(https://cdn.jsdelivr.net/gh/hongsigner/freesentation/freesentation.css);
	
## 적용

### css 적용 예

	body		{ font-family: 'Freesentation', sans-serif }
	.normal		{ font-weight: 400 }
	.bold		{ font-weight: 700 }
	.bolder		{ font-weight: 800 }
	.light		{ font-weight: 300 }
